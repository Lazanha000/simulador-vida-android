## 0.19.0 — Botão Voltar e memória de "onde eu estava" (2026-11-25)
Só interface (JavaScript/CSS, 1 linha de Python e 1 trecho de Kotlin); motor, regras, saves e RNG intactos.
- **Voltar**: toda tela de Ações (Estudar, Biblioteca, Redação/Artigos/Filmes, ENEM/faculdade, Carreiras, Mundo, Amigos, Encontros, Namoro, Onde conhecer) ganhou o botão **Voltar**, fixo no rodapé (visível mesmo em listas longas), que volta à tela anterior (o menu Ações). Área de estudo volta ao Foco. Esc também volta uma tela; tocar fora fecha.
- **Botão físico do Android**: `MainActivity.onBackPressed` pergunta ao JavaScript (`window.__simVoltar`), que fecha uma camada por vez (diálogo → painel → menu → tela de nova partida/carregar → título). Só fecha o app se não houver nada a voltar. Decisões e luto (não fecháveis) engolem o toque.

Nova partida lembra nome, modo, nome do personagem, sobrenome, sexo, irmãos/idade/filhos (a **semente nunca**, para não repetir o mesmo mundo sem querer; apaga ao criar).
